# Айра — установка сервера

Выполните от root на чистом Ubuntu 24.04:

    curl -fsSL https://raw.githubusercontent.com/Murzali1/aira-bootstrap/main/i.sh | bash

Скрипт создаёт пользователя `aira`, ключ доступа к закрытому репозиторию с кодом и спрашивает пароль для дашборда. Паролей и данных здесь нет.
